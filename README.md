# TV Gratis Argentina

1. Crea un repo en GitHub y sube estos archivos (Add file > Upload files).
2. En codemagic.io: Add application > GitHub > elige el repo > tipo "Flutter App" con codemagic.yaml.
3. Start new build > descarga el APK.
4. Editas assets/catalogo.json para agregar plataformas o películas.
